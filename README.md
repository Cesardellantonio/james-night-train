# James's Night Train

A calm bedtime animation: a little steam train named James rolls through a moonlit countryside,
stops at stations, crosses a river bridge and passes a field of sheep jumping a fence.

- Music-box lullabies (Twinkle Twinkle and Brahms' Lullaby), rail sounds, owls and crickets
- Tap the train, the moon, the sky or the fields
- Sleep timer: the scene dims, the train slows and stops, and it says goodnight
- Snow on and off, full screen, keeps the screen awake where the browser allows

## Files

- `app.html` is the page itself.
- `build.sh` wraps it into `index.html`, which GitHub Pages serves.

Edit `app.html`, run `./build.sh`, then commit both.
